# YouTube Agent Skill (11 skills /yt-*)

Origem: https://github.com/Jakeschincariol/youtube-agent-skill (commit a2feb21, licença MIT em `YOUTUBE-AGENT-LICENSE`).
Instalada em 14/11 a pedido do Patrik. As instruções estão em inglês, mas o Claude responde em português.

| Comando | Para quê |
|---|---|
| /yt-script | roteiro a partir de uma ideia, com ganchos (21 fórmulas) e nota |
| /yt-package | título + thumb avaliados juntos |
| /yt-edit | plano de edição a partir da transcrição (cortes, tempo morto) |
| /yt-shorts | cortes para Shorts |
| /yt-seo | descrição e SEO |
| /yt-chapters | capítulos |
| /yt-comment | respostas a comentários |
| /yt-plan | plano da semana |
| /yt-viral | ideias e padrões de vídeos virais |
| /yt-retention | lê a retenção e mostra onde o público sai |
| /yt-audit | auditoria do canal |

Perfil de voz (opcional): as skills leem `~/.claude/youtube/voice.md` se existir. Modelo em `YOUTUBE-AGENT-voice-template.md`.
Para atualizar: clonar o repositório de origem e copiar de novo `skills/yt-*` para esta pasta.
