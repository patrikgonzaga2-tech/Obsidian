# Kit HyperFrames · Pingo Pinta · cena da maçã

Este kit tem tudo para recriar a abertura + maçã do vídeo 01 no HyperFrames, no computador do Patrik.

| Arquivo | O que é |
|---|---|
| `PROMPT_HYPERFRAMES.md` | o texto para colar no Claude Code do terminal |
| `tempos.json` | quando entra cada fala e cada ação (em segundos) |
| `assets/maca.svg` | a maçã em vetor: contorno em 3 passos + áreas de tinta |
| `assets/pingo_<cor>.png` | o Pingo recortado em 8 cores (neutro + 6 do arco-íris + marrom) |
| `assets/mao_caneta.png` | a mão segurando o canetão (ponta da caneta no pixel 194, 197) |
| `assets/fala_01..15.mp3` | as 15 falas do Pingo (voz Liam) |

Requisitos do HyperFrames: Node.js 22 ou mais novo e FFmpeg instalados.
Fonte: https://github.com/heygen-com/hyperframes
