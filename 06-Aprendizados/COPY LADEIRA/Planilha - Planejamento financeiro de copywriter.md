# Planilha do curso: Planejamento financeiro de copywriter

Fonte: link de Google Sheets enviado pelo Patrik em 19/11/2026 (material do Módulo 05, "Como cobrar").
Link: https://docs.google.com/spreadsheets/d/1uIcMUS7cyIpxDVDj02BMKKUYf9vqRHOq_bkLRO7G3bY/edit

Modelo: uma meta de faturamento mensal (R$ 10 mil) e o que entra de cada tipo de contrato.

| Tipo | Valor de exemplo |
|---|---|
| Fee mensal · Performance Content Package | R$ 3.000/mês |
| Fee mensal · Performance Creatives Package | R$ 5.000/mês |
| Fee mensal · Full Package | (em branco) |
| Pontual · entrega para perpétuo | R$ 5.000 |
| Pontual · entrega para lançamento | R$ 15.000 |

Leitura: base de receita recorrente (fees) + picos com entregas pontuais (lançamento). Mês com lançamento bateu 230% da meta.
Uso para a agência PTK: separar pacote mensal de conteúdo, pacote mensal de criativos e entregas pontuais (página, VSL, lançamento).
